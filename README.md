# 🛒 Shoppit - Full-Stack E-Commerce Platform

A modern, responsive e-commerce web application featuring dynamic product catalogs, cart management, checkout with PayPal Sandbox integration, and user authentication.

## 🛠️ Tech Stack
- **Frontend**: React 19, Vite, React Router v7, Axios, Bootstrap 5, React Toastify, React Icons
- **Backend API**: Django REST Framework, Python, SimpleJWT Authentication
- **Payments**: PayPal JavaScript SDK (Sandbox)
- **Database**: SQLite3
