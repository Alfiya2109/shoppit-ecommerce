# 🛒 Shoppit - Full-Stack E-Commerce Platform

> 🔗 **Live Storefront Demo**: [https://shoppit-ecommerce.vercel.app](https://shoppit-ecommerce.vercel.app)  
> 💳 **Payment Gateway**: PayPal Sandbox Integration  
> 🛠️ **Tech Stack**: React 19, Vite, Bootstrap 5, Django REST Framework, SimpleJWT, SQLite3

---

## 🌟 Overview
**Shoppit** is a full-stack, responsive e-commerce web platform engineered with a decoupled architecture. It combines a dynamic React 19 storefront with a robust Python/Django REST Framework backend, providing users with a frictionless online shopping, cart management, and payment checkout experience.

---

## 🚀 Key Features

- 🛍️ **Dynamic Product Catalog**: Search, filter by categories, view high-res galleries, stock levels, and customer ratings.
- 🛒 **Real-Time Shopping Cart**: Persistent client cart with dynamic quantity updates, price calculations, and tax computation.
- 💳 **PayPal Sandbox Checkout**: Fully functional sandbox checkout flow with instant transaction verification and order receipt generation.
- 🔐 **Secure Authentication**: SimpleJWT user registration, login sessions, and protected order history dashboards.
- ⚡ **Toast Notifications & Feedback**: Instant visual feedback for cart modifications and order status updates using React Toastify.

---

## 🛠️ Tech Stack Details

- **Frontend**: React 19, Vite, React Router v7, Axios, Bootstrap 5, React Toastify, React Icons
- **Backend**: Django 5, Django REST Framework (DRF), Python 3.11+
- **Authentication**: SimpleJWT (JSON Web Tokens)
- **Payment Gateway**: PayPal JavaScript SDK (Sandbox Environment)
- **Database**: SQLite3
